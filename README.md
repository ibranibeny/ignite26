# Ignite 2026 session guide (unofficial)

A single-page guide to the Microsoft Ignite 2026 on-demand sessions: short summaries, key takeaways,
architecture views where a session describes one, the on-demand recording playing right in the page,
and personal playlists that play sessions back to back.

**Open the guide: https://ibranibeny.github.io/ignite26/**

- Search by product, topic or session code (press `/`), or browse by topic and session type.
- Save sessions to playlists. Playlists stay in your own browser; share one with a link or a code.
- Recordings stream from Microsoft's public Ignite video service; every session links to its page on ignite.microsoft.com.

Not an official Microsoft site. Summaries are written for this guide from each session's public description and recap.
